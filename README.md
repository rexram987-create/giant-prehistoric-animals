# ענקי הפרהיסטוריה שאחרי הדינוזאורים

אתר אנציקלופדי אינטראקטיבי בעברית על תשעה בעלי חיים ענקיים שחיו בעידן הקנוזואיקון, לאחר הכחדת הדינוזאורים שאינם עופות. האתר מותאם לטלפונים ולמחשבים ומחולק לפי אזורי מחיה.

**מצב הפרויקט (16 באוקטובר 2026):** המבנה המודולרי מוזג ל-`main` בבקשת משיכה #1 (מיזוג `d831898`), וגרסת הייצור נפרסה בהצלחה ב-Vercel. בעל האתר בדק ואישר שהאתר פועל ושהקישורים למקורות המדעיים נפתחים. הפיכת האתר ל-PWA עדיין לא בוצעה.

## מבנה הקבצים

```text
index.html
css/
  style.css
js/
  app.js
  navigation.js
  render.js
  events.js
data/
  habitats.json
  animals/
    index.json
    palaeoloxodon.json
    paraceratherium.json
    megatherium.json
    titanoboa.json
    megalodon.json
    livyatan.json
    perucetus.json
    argentavis.json
    pelagornis.json
```

- `index.html` — שלד הדף וקישור לקובצי העיצוב והסקריפטים.
- `css/style.css` — עיצוב רספונסיבי.
- `js/app.js` — מצב היישום וטעינת קובצי הנתונים.
- `js/navigation.js` — ניווט, מעבר בין בעלי חיים ותפריט צדדי.
- `js/render.js` — בניית תוכן הדפים, הלשוניות וקישורי המקורות.
- `js/events.js` — חיבור הכפתורים ואתחול האתר.
- `data/habitats.json` — קטגוריות אזורי המחיה.
- `data/animals/index.json` — רשימת בעלי החיים וסדר הצגתם.
- `data/animals/*.json` — נתונים נפרדים לכל בעל חיים.

## מה עוד נשאר לבצע

### עדיפות ראשונה — להפוך את האתר ל-PWA שניתן להתקין בטלפון

- [ ] ליצור `manifest.webmanifest` עם שם האפליקציה בעברית ובאנגלית, `start_url`, `scope`, `display: standalone`, צבעי ערכת הנושא וכיווניות מתאימה.
- [ ] ליצור סמלי אפליקציה מקוריים בקובצי PNG בגודל **192×192** ו-**512×512** לפחות, ולשקול סמל `maskable` נפרד.
- [ ] לקשר את המניפסט ואת `theme-color` ב-`index.html`.
- [ ] ליצור Service Worker (למשל `sw.js`) עם שמירה במטמון של קובצי האתר ונתוני ה-JSON, כדי לאפשר קריאה גם ללא אינטרנט אחרי טעינה ראשונית.
- [ ] להגדיר עדכון גרסאות מטמון כדי שתוכן מדעי מתוקן לא ייתקע בגרסה ישנה.
- [ ] לרשום את ה-Service Worker בדפדפנים תומכים ולטפל בשגיאות רישום.
- [ ] להוסיף ממשק התקנה בנייד כאשר הדפדפן תומך בכך, לצד הסבר להתקנה ידנית דרך תפריט Chrome כאשר אין אירוע התקנה זמין.
- [ ] לבדוק התקנה בפועל באנדרואיד, פתיחה במסך עצמאי, סמלי אפליקציה, עבודה במצב טיסה, רענון לאחר פריסה חדשה והסרה/התקנה מחדש.
- [ ] להריץ בדיקת PWA וכלי נגישות ולתקן בעיות שיתגלו.

**חשוב:** אין לסמן את שלב ה-PWA כהושלם לפני יצירת הקבצים, פריסתם ובדיקת ההתקנה והעבודה הלא-מקוונת במכשיר אמיתי. האתר כבר מוגש ב-HTTPS דרך Vercel, אך HTTPS לבדו אינו הופך אותו ל-PWA.

## עבודה ופיתוח מקומי

האתר הוא אתר סטטי ללא תהליך בנייה מחייב. מאחר שהנתונים נטענים באמצעות `fetch`, יש לפתוח אותו דרך שרת HTTP מקומי ולא באמצעות `file://`.

לדוגמה:

```bash
python -m http.server 8000
```

לאחר מכן פותחים `http://localhost:8000`.

## פריסה ועדכונים

ענף העבודה הראשי הוא `main`. פריסת הייצור ב-Vercel מחוברת למאגר GitHub. שינוי שנדחף ל-`main` יכול להפעיל פריסה חדשה בהתאם להגדרות הפרויקט; מומלץ לוודא שהפריסה הגיעה למצב **Ready** ולבדוק את האתר לאחר כל שינוי.

לשינויים גדולים, כגון הוספת PWA, מומלץ לעבוד בענף נפרד, לבדוק תצוגה מקדימה, ורק לאחר אישור למזג ל-`main`.
