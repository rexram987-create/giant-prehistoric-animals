# ענקי הפרהיסטוריה שאחרי הדינוזאורים

אתר אנציקלופדי אינטראקטיבי בעברית על תשעה בעלי חיים ענקיים שחיו בעידן הקנוזואיקון, לאחר הכחדת הדינוזאורים שאינם עופות. האתר מותאם לטלפונים ולמחשבים ומחולק לפי אזורי מחיה.

**מצב הפרויקט (16 באוקטובר 2026):** עדכון PWA, קריאה ללא אינטרנט, קישורים ישירים, נגישות ותיקוני תוכן מוזג ל־`main` בבקשת מיזוג #2 ונפרס בהצלחה ב־Vercel (מיזוג `662bbf1`). בעל האתר אישר שהתצוגה המקדימה תקינה. בעל האתר אישר ב־16 באוקטובר 2026 שהיישומון הותקן ופועל בטלפון וגם במצב טיסה. עדכון תשע תמונות השחזור ביחס 16:9 אושר בידי בעל האתר, מוזג בבקשת מיזוג #3 ונפרס ב־Vercel (מיזוג `1377e62`). ההקראה בעברית נבדקה ואושרה בטלפון, מוזגה בבקשת מיזוג #4 ונפרסה לאתר הפעיל.

## עבודה ופיתוח מקומי

האתר הוא אתר סטטי ללא תהליך בנייה מחייב. מאחר שהנתונים נטענים באמצעות `fetch`, יש לפתוח אותו דרך שרת HTTP מקומי ולא באמצעות `file://`.

לדוגמה:

```bash
python -m http.server 8000
```

לאחר מכן פותחים `http://localhost:8000`.

## פריסה ועדכונים

ענף העבודה הראשי הוא `main`. פריסת הייצור ב-Vercel מחוברת למאגר GitHub. שינוי שנדחף ל-`main` יכול להפעיל פריסה חדשה בהתאם להגדרות הפרויקט; מומלץ לוודא שהפריסה הגיעה למצב **Ready** ולבדוק את האתר לאחר כל שינוי.

לשינויים גדולים, כגון הוספת PWA, מומלץ לעבוד בענף נפרד, לבדוק תצוגה מקדימה, ורק לאחר אישור למזג ל-`main`.

## בדיקות לעדכון

הבדיקות אינן דורשות התקנת חבילות. עם Node.js 24:

```bash
node --test tests/*.test.cjs
```

30 בדיקות מכסות טעינה חלקית, כתובות, Escape ומיקוד, קישור דילוג, מניפסט וגדלי סמלים, כל תשעת קובצי התוכן במטמון, ניווט לא מקוון, המתנת גרסה חדשה ורענון לשוניות, הצגת כל תשע התמונות ושמירתן לקריאה ללא אינטרנט. בדיקות ה־Service Worker מריצות את קוד האירועים בסביבה מבוקרת; הן אינן תחליף לבדיקת מצב טיסה במכשיר אמיתי.

השוואת הגדלים עדיין טקסטואלית. תשע התמונות הן שחזורים משוערים שנוצרו בבינה מלאכותית, ואינן תיעוד מדעי של המראה או קנה המידה. הן ב־WebP בגודל 1600×900 (16:9), מוצגות ללא חיתוך ונשמרות במטמון. תמונות הראש של פרוצטוס משוערות במיוחד משום שלא נמצאה גולגולת. הנחיות היצירה והתיעוד נמצאים ב־`images/README.md` וב־`images/prompts.md`.
