# ענקי הפרהיסטוריה שאחרי הדינוזאורים

אתר אינטראקטיבי המציג את יצורי הענק שחיו ביבשה, בים ובאוויר בעידן הקנוזואיקון לאחר הכחדת הדינוזאורים.

## קטגוריות ובעלי חיים באתר
- ענקי היבשה: פלאולוקסודון נמדיקוס, פרצרתריום, מגתריום, טיטאנובואה
- ענקי הים והאוקיינוסים: מגלודון, לווייתן מלוויל, פרוצטוס קולוסוס
- ענקי האוויר והשמיים: ארגנטוויס, פלגורניס סנדרסי

## תכונות האתר
- כיווניות מלאה בעברית (RTL)
- כותרת עליונה
- תפריט המבורגר צדדי לפי 3 אזורי מחיה לניווט לדף נפרד לכל בעל חיים
- מצב תצוגת כרטיסיות בלשוניות או תצוגה רציפה
- הצגה או הסתרה של מונחים מדעיים בלטינית

## מבנה מודולרי (ענף refactor/modular-structure)
- `index.html` — שלד הדף וקישורים לקובצי CSS ו-JavaScript.
- `css/style.css` — עיצוב.
- `js/app.js` — מצב היישום וטעינת נתונים באמצעות `fetch`.
- `js/navigation.js` — ניווט ותפריט.
- `js/render.js` — הצגת תוכן.
- `js/events.js` — חיבור אירועי ממשק ואתחול.
- `data/habitats.json` — אזורי מחיה.
- `data/animals/index.json` — סדר בעלי החיים.
- `data/animals/*.json` — רשומה נפרדת לכל בעל חיים.

הנתונים נטענים מנתיבים יחסיים המתאימים ל-GitHub Pages. לפתיחה מקומית יש להשתמש בשרת HTTP ולא ב-`file://`. השינוי אינו כולל עדיין תמונות חדשות או תיקונים מדעיים.
