# ענקי הפרהיסטוריה שאחרי הדינוזאורים

אתר אנציקלופדי אינטראקטיבי בעברית על תשעה בעלי חיים ענקיים שחיו בעידן הקנוזואיקון, לאחר הכחדת הדינוזאורים שאינם עופות. האתר מותאם לטלפונים ולמחשבים ומחולק לפי אזורי מחיה.

**מצב הפרויקט (16 באוקטובר 2026):** גרסת הייצור הקודמת פועלת ב־Vercel. בענף `feat/pwa-accessibility-science` נוסף עדכון הכולל PWA, קריאה ללא אינטרנט, קישורים ישירים, נגישות ותיקוני תוכן. עד למיזוג ולפריסה, תכונות העדכון זמינות רק בתצוגה המקדימה. התקנה ומצב טיסה במכשיר Android אמיתי עדיין מחייבים אישור של בעל האתר.

## מה עוד נשאר לבצע

### PWA — מומש, נדרשת בדיקת מכשיר אמיתי

- [x] מניפסט עברי RTL, פתיחה כ־`standalone` וסמלי PNG מקוריים 192/512, כולל maskable וסמל Apple.
- [x] כפתור התקנה כשאירוע ההתקנה נתמך; הסבר התקנה ידנית בכל יתר המקרים.
- [x] Service Worker השומר את כל תשעת קובצי בעלי החיים, הקטלוג וקובצי הממשק. לאחר הופעת ההודעה „התוכן נשמר לקריאה ללא אינטרנט”, אפשר לקרוא גם דפים שלא נפתחו קודם.
- [x] כל גרסה נשמרת כמכלול. עדכון ממתין מוצג בכפתור „גרסה חדשה זמינה — עדכן”; לאחר אישורו, הלשוניות הפתוחות מתרעננות והקישור הנוכחי נשמר.
- [x] המקורות החיצוניים אינם נשמרים במטמון ודורשים אינטרנט.
- [ ] למזג ולפרוס לאחר סקירת התצוגה המקדימה.
- [ ] לבדוק באנדרואיד אמיתי: התקנה ב־Chrome, סמל במסך הבית, פתיחה עצמאית, מצב טיסה ופתיחת כל תשעת הדפים, עדכון גרסה והתקנה מחדש.
- [ ] בדיקת קורא מסך ומכשירים נוספים.

**שמירת גרסאות:** בכל שינוי לקובץ שמופיע ב־`PRECACHE` יש לעדכן את `CACHE_NAME` ב־`sw.js`. קובצי התוכן מוגשים מהגרסה הפעילה במטמון עד לקבלת העדכון, כדי למנוע ערבוב בין גרסאות. ההודעה על זמינות ללא אינטרנט תלויה בהשלמת השמירה בפועל; הדפדפן עשוי למחוק מטמון אם המשתמש מנקה נתוני אתר או אם חסר מקום.

## עבודה ופיתוח מקומי

האתר הוא אתר סטטי ללא תהליך בנייה מחייב. מאחר שהנתונים נטענים באמצעות `fetch`, יש לפתוח אותו דרך שרת HTTP מקומי ולא באמצעות `file://`.

לדוגמה:

```bash
python -m http.server 8000
```

לאחר מכן פותחים `http://localhost:8000`.

## פריסה ועדכונים

ענף העבודה הראשי הוא `main`. פריסת הייצור ב-Vercel מחוברת למאגר GitHub. שינוי שנדחף ל-`main` יכול להפעיל פריסה חדשה בהתאם להגדרות הפרויקט; מומלץ לוודא שהפריסה הגיעה למצב **Ready** ולבדוק את האתר לאחר כל שינוי.

לשינויים גדולים, כגון הוספת PWA, מומלץ לעבוד בענף נפרד, לבדוק תצוגה מקדימה, ורק לאחר אישור למזג ל-`main`.

## בדיקות לעדכון

הבדיקות אינן דורשות התקנת חבילות. עם Node.js 24:

```bash
node --test tests/site.test.cjs
```

16 בדיקות מכסות טעינה חלקית, כתובות, Escape ומיקוד, קישור דילוג, מניפסט וגדלי סמלים, כל תשעת קובצי התוכן במטמון, ניווט לא מקוון, המתנת גרסה חדשה ורענון לשוניות. בדיקות ה־Service Worker מריצות את קוד האירועים בסביבה מבוקרת; הן אינן תחליף לבדיקת מצב טיסה במכשיר אמיתי.

השוואת הגדלים עדיין טקסטואלית. תמונות ושחזורי בעלי חיים, השוואה חזותית וקולות אינם חלק מעדכון זה.
