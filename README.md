# ענקי הפרהיסטוריה שאחרי הדינוזאורים

אתר אינטראקטיבי המציג את יצורי הענק שחיו ביבשה, בים ובאוויר בעידן הקנוזואיקון לאחר הכחדת הדינוזאורים.

## קטגוריות ובעלי חיים באתר
- ענקי היבשה: פלאולוקסודון נמדיקוס, פרצרתריום, מגתריום, טיטאנובואה
- ענקי הים והאוקיינוסים: מגלודון, לווייתן מלוויל, פרוצטוס קולוסוס
- ענקי האוויר והשמיים: ארגנטוויס, פלגורניס סנדרסי

## תכונות האתר
- כיווניות מלאה בעברית (RTL)
- כותרת עליונה
- תפריט המבורגר צדדי לפי 3 אזורי מחיה לניווט לדף נפרד לכל בעל חיים
- מצב תצוגת כרטיסיות בלשוניות או תצוגה רציפה
- הצגה או הסתרה של מונחים מדעיים בלטינית
